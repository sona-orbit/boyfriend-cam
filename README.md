# Boyfriend Cam (男朋友相機)

Website for **Boyfriend Cam** — an iPhone camera that quietly tells you how to frame the shot while you are taking her photo.

Served by GitHub Pages at https://sona-orbit.github.io/boyfriend-cam/

- Home, privacy and support pages in English, 繁體中文, 简体中文, 日本語, 한국어 and ไทย
- Static HTML/CSS, no build step on this repository
